## About Me

I learned to build software in a place where the connection drops mid-request, most people pay with mobile money, and one screen has to work in French and in English. That shaped how I work: I assume the network will fail, I keep things light, and I test on the phone people actually own.

I started as an intern and ended up leading the team. Along the way I've built testing tools, a fintech back office, and platforms that government services run on every day. I like owning a feature from the database to the last pixel, and when something has to ship, I see it through to the end. I don't call it done until it actually works for the people using it.

Lately I've been putting AI to work inside real products, such as search that understands what people mean and voice interviews that run by themselves, while building my own marketplace for renting homes in Congo.

Away from the keyboard: basketball, anime, and helping junior developers get unstuck.
